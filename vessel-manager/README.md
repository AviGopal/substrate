# Vessel Manager

A comprehensive vessel management system for MiniBob that provides:

- Vessel discovery and registration
- Lifecycle management (start, stop, restart)
- Health monitoring and status tracking
- Resource usage monitoring
- Configuration management
- Logging and metrics collection

## Structure

- `src/` - Source code
- `tests/` - Test files
- `docs/` - Documentation

## Usage

```bash
# Start the vessel manager
python src/main.py
```
