BLOCKER ANALYSIS
=============================================================================

WORKING STEPS (1-9):
  ✅ K8s infrastructure deployed
  ✅ Secrets injected as env vars
  ✅ Git configured (user.name, user.email)
  ✅ Branch creation works
  ✅ Commit operations work
  ✅ git push works

FAILING STEP (10):
  ❌ gh pr create fails
  
  Root Cause:
    → gh CLI not authenticated
    → Caused by: GITHUB_TOKEN="none" in Step 1
    → gh auth login fails in Step 3
    → gh pr create fails in Step 10

RESOLUTION:
  Replace GITHUB_TOKEN in devbob-secrets:
  
  kubectl patch secret devbob-secrets -n metabob --type='json' \
    -p='[{"op": "replace", "path": "/data/github-token", "value": "'$(echo -n "ghp_REAL_TOKEN" | base64)'"}]'
  
  kubectl rollout restart statefulset/devbob -n metabob
