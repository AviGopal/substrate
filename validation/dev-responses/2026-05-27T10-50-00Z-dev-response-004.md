## inv-028 C — resolveInputs poll-and-wait

**Audit's framing:**

> Slot-binding fires events but does NOT block. engine.ts:84-125: before each task with declared inputShapes, executor scans runtime.store.all(), computes missingShapes, emits lifecycle:task:preBinding AND lifecycle:gap:classified (when missing > 0). Then proceeds immediately to task.started and resolveInputs at :127, :134. resolveInputs (:450-478) hard-throws if no candidate exists (:465-467)... In practice this works because dispatch happens to be synchronous enough; the design is fragile.

**Fix (`ias-executor-ts` local commit `37a9ddb`):**

Converted `resolveInputs` to `async` with a per-shape polling loop. Each missing shape is polled every 50ms until either the shape appears in the store or the configurable deadline elapses.

```typescript
const timeoutMs = parseInt(process.env["EXECUTOR_INPUT_RESOLUTION_TIMEOUT_MS"] ?? "0", 10);
const deadline = Date.now() + Math.max(0, timeoutMs);
// ...
while (candidates.length === 0 && Date.now() < deadline) {
  await new Promise((r) => setTimeout(r, 50));
  candidates = filterCandidates();
}
```

**Backward-compatible by default:** `EXECUTOR_INPUT_RESOLUTION_TIMEOUT_MS` defaults to `0`, preserving the original "throw immediately" behavior. Live substrate runs unchanged. Operator opts in by setting the env var when slot-binding subscribers grow more asynchronous (e.g. cross-vessel binding).

**Error message** updated to surface the wait window when timeout > 0:
```
Task 't1' requires shape 'X' but no matching impulses were found
(waited 5000ms for slot-binding subscribers)
```

**Tests (4/4 pass):**
- `timeout=0`: throws immediately when shape missing (<200ms)
- `timeout=800`: throws only after the wait window (~800ms)
- `timeout=2000`: succeeds when subscriber populates store at +250ms
- present-from-start: shapes already in store resolve immediately even with timeout set

**Baseline (full suite):** unchanged at 557 pass / 9 fail / 1 error — all pre-existing, verified via `git stash`. No regressions.

**Live verification (10:33Z):**

Built dist, deployed to substrate, restarted goal-host-vessel. Triggered probe-reachable-unlearned dispatch with no env var set — completed normally (default `timeout=0` preserved).
