# validation/reports — working records

These are the project's working records, not user documentation. How the system behaves is
described under [`docs/`](../../docs/README.md).

- **`realignment-2026-09-29/REALIGNMENT.md`** is the plan the project executes toward
  self-sufficiency: what each part of the system must do, how it is measured, and an
  append-only log of the decisions taken along the way. It is written as a working record,
  so it names shortfalls plainly: naming a shortfall is how it becomes work.
- **Ledgers** (`autonomy-ledger-*`, `causal-attempt-ledger/`) are appended by tooling outside
  the repository and read by the measures that cite them.
- **Audits** (`self-development-program-*`, `env-ratchet-*`) are point-in-time readings that
  later decisions cite as evidence.

A record here is kept while something reads it or a decision cites it.
