## Cross-cutting findings for this area

1. **The authoritative doc names a fossil as its validator.** CLAUDE.md §Validation says "the failure-mode harness … plus a confirming dispatch". The harness last ran on 07-05 with an invalid LIFT claim, and its activity form has 0 executions. The live acceptance mechanism is install-acceptance CI, which succeeds, files gaps and executes the README verbatim. This is a docs-align item: fix it through the docs-align loop, not by hand in this pass.
2. **The only live "validation" mechanism is the one that routes its failures back into the substrate as gaps (I).** Everything else in `validation/scripts` was an external operator gate. Under the operating model (route around, then encapsulate by evidence), the salvage is the *fixtures and known answers* (C), turned into deterministic oracle rows at goal-host's reach seam, not the scripts.
3. **The "fossil" label on the scenario corpus is wrong (G).** It is the drafter's live input queue, ~12% of all executions, and it is split across three diverging copies. Its fix is shape-based resolution against the gap store. It must not be archived before its readers move.
4. **Live state depends on report directories (R, and G through git).** A running container mounts `validation/reports/syzygy-…/surface-host.conf`, and the autonomous lane commits runtime scenario files (`edc68d49`). Both violate the placement law. A cleanup that deletes "old reports" would break production, so any archive step must first check `docker inspect` mounts and src readers.
5. **Silent skips that pose as gates:**
   - The weekly CI failed on every run for 4+ months, on a missing secret (A).
   - The closure audit read HTTP 0 as "not closed" (D).
   - The lift flip came from a harness fallback (B).

   All three are the MEMORY class "a silent skip reads as a pass" or "a negative with no positive control". The detector for the class is the install-acceptance pattern: failures post as gaps. A CI job that has not produced a single pass in N runs should itself file a gap.
