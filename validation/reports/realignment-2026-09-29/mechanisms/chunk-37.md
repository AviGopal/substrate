## Cross-cutting findings (class grain)

1. **The same thing keeps recurring for the same reason: operator hooks hardcode `localhost:18xxx`.** Four operator-side mechanisms fail silently for one reason: #4, #6's S3 branch, the MCP `goal_status`/`registry_query`, and 21 validation scripts (endpoint-routing, validation-other-3). The reason is that `localhost` resolves to `::1` under podman/pasta, and none of these tools read the substrate-connect client config. Fixing them one hook at a time repeats the pattern this realignment is meant to end. The seam is **one endpoint resolver for all operator tooling**: read the emitted client config, fall back to `127.0.0.1`, and print a line when unreachable. A probe that asserts each hook's output is non-empty would be the class detector.
2. **Silent fail-open again: a gate whose failure has no reader.** Examples: the placement gate is inert and logs a warning nobody reads (#1); gitleaks is skipped via `command -v` (#2); session-start exits 0 with 0 bytes (#4); session-end reaches by a read (#5). This is the standing law "a silent skip reads as a pass", broken four more times in one small area.
3. **Two hook mechanisms compete for one `core.hooksPath` slot.** The attempt-ledger recorder (#3, live and read by 8 dev-vessel/goal-host modules) and the placement gate (#1, inert) are both git hooks in the container, but only the recorder won the slot. The repair is to make the ledger dir chain `pre-commit` to the repository's own hook. That keeps both, adds nothing new, and closes the root-residue class, which the collectors counted at 11 recurrences.
