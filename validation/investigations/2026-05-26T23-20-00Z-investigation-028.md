## Part B — `audit-resolver-divergence` activity

### Shape contract

- **Location:** development-vessel (co-located with substrate-runtime metadata)
- **Input shapes:** `resolverRegistry` (from goal-host-vessel registry + discovery /shapes), `traceWindow` (existing `executionTraceWithSignatures`), `expectationSet` (`description_of` + `playbook` concepts from concept-db keyed on `resolver:<id>`)
- **Output shapes:** `resolverDivergenceReport` (per-resolver: contract summary, observed stats, divergence list, severity), `expectationGap` (consumable by existing `draft-gap-closing-activity`), `memoryNote(type=finding, scope=resolver-audit)` for operator-side cache mirror

### Task graph (mostly deterministic; LLM reserved for ambiguous band)

1. `enumerate_resolvers` — impulse-resolve over `resolverRegistry`.
2. `fetch_expectations` — impulse-resolve over `relatedConcepts(subject=resolver:${id})` per resolver. Cold-start: operator-authored for 5 built-ins. Mature: **ribosome promotion** — after ≥10 fires with stable signature (same in/out histograms, duration within 1.5× MAD), ribosome emits `description_of(resolver_id)` automatically. New resolvers acquire descriptions after ~10 fires, no human required.
3. `fetch_trace_window` — impulse-resolve `executionTraceWithSignatures` since=now-1h, limit=500.
4. `per_resolver_iteration` — `iteration` resolver fanning out, each iter:
   - `compute_observed_stats` — deterministic. Median/p95 duration, mean in/out counts, success rate, modal output shape.
   - `compare_to_expectation` — deterministic per-axis comparison.
   - `grade_severity` — deterministic threshold table; **LLM (`llm-prompt`) ONLY for ambiguous-band**. Keeps cost low and keeps the audit itself auditable.
5. `assemble_report` — deterministic aggregator.
6. `emit_findings` — `learning_signal_writer` writes memoryNote + expectationGap impulses; `draft-gap-closing-activity` picks them up.

### Trigger (no new lifecycle channels needed)

- **`lifecycle:substrate:idle` cadence** — boredom-vessel rotation slot. Cheap; reuses FTS-indexed trace window.
- **`lifecycle:gap:detected` reactive** — when `escalate-unknown-shape` or `coverage-tick` emits a gap whose suspected cause is "resolver contract drift", they dispatch this activity directly.

### Recursion

The audit uses `impulse-resolve` (×3), `iteration`, `learning_signal_writer`, occasional `llm-prompt`. It audits resolvers including its own dependencies. **Guard: emittingTemplateId exclusion** (already exists in `lifecycle-subscriptions.ts`) — when computing observed stats for resolver X, exclude traces whose `composition_chain` contains an `audit-resolver-divergence` execution.

The auditor will eventually flag its own `impulse-resolve` calls as showing the in=N/consumed=0 anti-pattern (Finding A3) — which is correct and useful — and the substrate will propose either fixing the binding layer or updating the `description_of(impulse-resolve)` concept to declare advisory-only inputs.

### Operational implication

Today: divergences surface when an operator reads source + traces. Cadence: human-attention-limited, days to weeks. Coverage: whichever resolvers the operator picks.

With this activity on idle-cadence: every ~5 minutes, all resolvers scored against declared envelopes. Divergences with sound provenance land in the impulse pool. Operator sees `resolverDivergenceReport` memoryNote instead of doing audit themselves. `expectationGap` impulses feed `draft-gap-closing-activity`, which proposes fixes.

**S2→S3 push-away progress signal:** when the substrate refuses an operator intervention citing `interventionRefused(rationale: resolverDivergenceReport[T] shows resolver X within envelope)`, that's the push-away criterion realized.

### Meta-audit — cheapest experiment

Run the activity for 24h of idle cadence. Sample 10 `expectationGap` impulses at random. Manually classify:
- (a) true divergence operator agrees with → activity is paying rent
- (b) false positive (envelope was wrong) → tighten envelopes
- (c) noise (degenerate / trivially fixable) → tighten threshold table

If ≥6/10 land in (a) → promote to boredom rotation permanently, gate future resolver registrations on having a `description_of` concept.
If ≥5/10 in (b)+(c) → pause activity, fix cold-start concepts, repeat 24h.

The classification itself becomes a `goal_verification_label` (migration-101 oracle corpus) — the meta-audit accrues into the same learning loop as template-quality verdicts.
