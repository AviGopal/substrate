## F-143 (MEDIUM): Promote-Gate K=0 Bug — Projection Engine Unreachable

The promote-gate was designed to perform Beta-Binomial projection over K nearest neighbors (K=5 default) using Jaccard similarity on template shapes. **K is 0 for every test.**

**Expected behavior**: `coverage-tick` template has `output_shapes=['coverageReport']`, `proposed=False`. For `test-gate-overlap` with `output_shapes=['coverageReport']`, the Jaccard similarity should be at minimum `1/5 = 0.2` (1 shared shape / 5 total union). K should be ≥ 1, triggering the statistical projection.

**Actual behavior**: K=0 on all 7 promote_gate_below_threshold refusals, including all 3 attempts for `test-gate-overlap` with exact output_shape match.

**Evidence:**
```bash
# coverage-tick IS in the registry with matching output_shape:
curl 'http://localhost:18080/v2/activities/templates?q=coverage-tick' \
  -H 'Authorization: ApiKey $METABOB_API_KEY' \
  | jq '.templates[0] | {id, output_shapes, proposed}'
# → {id: "activity:⟨development-vessel:coverage-tick⟩",
#    output_shapes: ["coverageReport"], proposed: false}

# But promote-gate reports K=0:
curl 'http://localhost:18080/v2/activities/promote-gate/stats' \
  -H 'Authorization: ApiKey $METABOB_API_KEY' \
  | jq '{mean_k, by_reason}'
# → {mean_k: 0, by_reason: {cold_start_no_similar: 1}}
```

**Consequence**: The Beta-Binomial projection is dead code. Every template promotion attempt is refused as `cold_start_no_similar` regardless of whether matching templates exist in the registry. The promote-gate as deployed cannot distinguish a genuinely novel template from one with a well-known output shape — it refuses both.

**Likely cause**: The SurrealDB candidate query is either:
1. Filtering by org_id that doesn't match the seeded development-vessel templates (tenant isolation mismatch)
2. Querying a wrong table name (`activity` vs `activity_template` with different tenancy)
3. Using a field that's null on seeded templates (e.g. `retired` field doesn't exist on seed rows and the `retired=false` filter is excluding them)

The gate blocks promotions, which is safe behavior. But the mechanism is wrong: it's not statistical projection, it's unconditional refusal.
