## Event-to-frame projection

| Event | Action |
|-------|--------|
| `activity.started` | `frames.set(executionId, {...})` with all fields initialized |
| `lifecycle:task:completed` (preferred) | `frame.taskIndex++, costToDateUsd += data.costUsd, impulseIds.push(...data.outputImpulseIds)` |
| `lifecycle:task:preBinding` | Update `frame.currentMissingShapes` |
| `activity.completed` / `lifecycle:execution:succeeded` | `status:"completed", completedAt:now` |
| `activity.failed` | `status:"failed", completedAt:now` |
| TTL reaper (30s `setInterval`) | Delete frames where `status != "running" && completedAt + 30000 < now` |

**Critical**: pick EITHER `task.completed` OR `lifecycle:task:completed` (they fire pair-wise; double-counting inflates taskIndex). Prefer lifecycle variant for cost.

## Multi-tenancy gap (NEW finding)

`events.ts:74` injects `source_vessel_id` but NOT `orgId`. Engine events arrive on observer without org tag. Broadcast-scope events fan to all clients (`broadcaster.ts:78-90`) gated only by `authenticated`, not `orgId`.

**Three remediation paths** (ranked):
1. **Best**: amend `events.ts` to extract `orgId` from `getJwtAuthFromContext(c)` on publish hop and inject `data.orgId`. Observer stamps `frame.orgId`; `GET` filters by caller's orgId. ~5 LOC.
2. **Fallback**: observer indexes by `source_vessel_id`; map vessel→org via discovery. Brittle.
3. **Defer**: ship broadcast-only (admin-only read) until multi-tenant infra lands. Acceptable today since substrate is single-org.

**Recommendation (1)** — also unblocks WS `emitToOrg` correctness for future subscribers.

## What the observer CANNOT serve (per iter-060)

- `loaded: bool` per impulse (runtime concept in `runtime.store`)
- `byteCount` (requires impulse bodies, dropped at trace-sink)
- Pool snapshot mid-task (only sees post-event slices; pre-task pool visible via `lifecycle:task:preBinding.currentImpulseShapes` but not bodies)

**Coexist with goal-host /state, not subsume**:
- Observer owns: identity, lineage, progress, cost, impulse IDs, missing shapes (at preBinding boundary)
- /state would own: hot pool contents, loaded flags, byte counts, intra-task snapshots
- Observer is lighter MVP; /state deferred until concrete need (debugging wedged engine)

## Composition with Finding 23

Confirmed: Finding 23 fix is engine-local `visibleImpulseIds: Set<string>` preventing cross-execution pool contamination INSIDE a single engine process. Observer's per-execution `impulseIds[]` accumulator is constructed from `outputImpulseIds` *emitted* per task — never sees `store.all()`, can't contaminate. Different layer, complementary.
