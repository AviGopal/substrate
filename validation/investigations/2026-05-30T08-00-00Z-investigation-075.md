## LiveExecutionFrame interface (verified subagent #42)

```typescript
interface LiveExecutionFrame {
  executionId: string;
  templateId: string;
  selectedTemplateId?: string;
  startedAt: number;
  completedAt?: number;
  taskIndex: number;
  costToDateUsd: number;
  status: "running" | "completed" | "failed";
```

**Stored**: executionId, templateId, startedAt, completedAt, taskIndex, costToDateUsd, status, parent/chain, impulseIds.
