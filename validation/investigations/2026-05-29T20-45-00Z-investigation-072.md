## The fix recommendation (subagent's commit)

**Three-layer fix needed (~50 LOC + process change)**:

1. **Pre-publish cite-checker** (`validation/scripts/cite-check.ts`, ~50 LOC bun):
   - Extracts `path:line(-line)?` patterns from investigation markdown
   - Runs `git grep -n` against the cited path at HEAD
   - Fails publish if (i) file doesn't exist, (ii) line range out-of-bounds, (iii) cited content doesn't textually overlap any quoted snippet in citing paragraph
   - Catches syntactic class (~30%): line-rot, missing files, wrong shape names

2. **Mandatory inline grep at filing-time** (structural process change):
   - Every load-bearing cite must include the actual grep output inline
   - Pattern: `\`\`\`\n$ grep -n "..." path\nline:result\n\`\`\``
   - Subagent #39's verified case: proxy-catch cite survived 5 propagations because subagent #29 filed inline; iter-037 didn't

3. **Multi-layer grep for layer-confusion class** (semantic, requires subagent verification):
   - 5 of 10 retractions are layer-confusion (cite valid but at wrong vessel/file)
   - Tooling can't catch this; requires subagents that explicitly check ALL layers (goal-host runtime + dev-vessel + ias-executor-ts + activity-api)
   - Subagent #29/#33/#35 modeled this correctly; subagents #24/iter-037 didn't
