## F-083: Officially Debunked and Closed

Investigation-027 carried F-083 as CRITICAL OPEN — the concern that `UPSERT activity:${id} CONTENT {...}` at lines 1200/5268 of `activities.ts` was overwriting Thompson posteriors on every template registration.

Between 01:00Z and 02:24Z, the substrate's devbob agent authored `validation/findings/f-083-debunked.md` (commit 612521ce), providing the definitive analysis. The auditor independently re-examined and concurs.

**The error**: The audit grep pattern `UPSERT activity.*CONTENT` is too broad. It matches two code paths:

1. **Lines 1200/5268 (matched by grep)** — template registration: `UPSERT activity:${activityId} CONTENT {...}`. These operate on the `activity` table (template definitions — name, description, tasks, shapes). Full CONTENT replacement is **correct semantics** here: re-seeding a template should overwrite the stored definition entirely. These have nothing to do with Thompson posteriors.

2. **F-069's target (not matched by above grep)** — posterior updates on `variant_performance_metrics`. These were fixed from CONTENT to SET in commit c1364e4. The correct verification grep:

```bash
docker exec substrate-live grep -n 'variant_performance_metrics.*SET' /vessels/activity-api/src/routes/activities.ts
# → lines 1249, 1269, 5291 (all SET)

docker exec substrate-live grep -n 'variant_performance_metrics.*CONTENT' /vessels/activity-api/src/routes/activities.ts
# → (empty — no CONTENT upserts on posteriors)
```

**Empirical proof**: validator-dispatch α has grown monotonically across all investigations:
- Investigation-020: α≈3500
- Investigation-026: α=3759
- Investigation-027 (00:05Z): α=3885
- Investigation-027 (02:24Z): α=4329
- Investigation-028 (05:06Z): α=4370

A CONTENT replacement would reset α to 1 on every container restart. The unbroken monotonic growth across the container's 15+ hour uptime proves posteriors are safe. **F-083 is closed. No deployment of c1364e4 is needed — it was already deployed.**

The substrate's independent analysis (f-083-debunked.md) reached the same conclusion, which the auditor discovered during investigation-028 review. This continues the exceptional self-diagnosis pattern noted in F-093 (investigation-027).
