## Recursion safety: author-skip

The detector is itself an activity. Its own task failures would fire `lifecycle:gap:classified`, which it subscribes to → infinite recursion.

**Pick (a) author-skip** mirroring ribosome at `ribosome-extract.json:69`. Task 2 checks `event.execution.template_author` against the detector's own id and short-circuits to `{skip:true}`.

Rejected: (b) depth-cap is fragile (legitimate deeply-nested goals would file no gaps); (c) no-self-emit requires engine surgery for a single consumer, violates "activities own their hygiene."

**Known property of author-skip**: leaves the detector's own failures invisible to *itself*. Acceptable — detector is deterministic; its own failures (DB unreachable, malformed event) belong in the substrate-health channel, not the gap channel.

## Aggregation: dedup + severity-driven filing (signal-to-noise guarantee)

```
Occurrence 1     → write substrateGap at severity=minor, NO notify
Occurrences 2-9  → UPSERT increment counter
  - At 3:        → escalate to severity=substantive
Occurrence 10+   → escalate to severity=blocking, emit `substrateGap:escalated` lifecycle event
```

**Closer subscribes to `substrateGap:escalated`, not raw filing.** This is the load-bearing signal-to-noise guarantee: a single transient `synthesis-failure` (LLM hiccup, context overflow) doesn't queue closure work. Persistent failures do.

Sliding-window option rejected: time-based windows lose information across substrate restarts. Occurrence counters on the impulse row survive.

Thresholds 3 and 10 hardcoded for V0 (see §7).
