The empty `recommendations[]` array triggers the existing "no template id returned" error path in `goal-host.ts`, so legacy callers fail rather than dispatching a wrong template. Callers that read the `refusal` field get structured rationale.

## Why the §27.S.6 Claim Is Overstated (F-129)

The CLAUDE.md definition is unambiguous:

> S3 has no acceptance gate. It is emergent and operator-measured by **active push-away** — substrate gates refusing operator interventions with cited evidence (`interventionRefused` impulses), not by passive intervention-absence.

CORE_IDIOMS.md Idiom 11 is equally specific:

> **Definition.** The substrate refuses an operator action with substrate-side evidence: refusing gate identity, refusal code, trace ids, posterior state, validator verdict, and a foundation citation. **The refusal is itself an `interventionRefused` impulse.** The trend in refusal rate (versus operator intervention rate) under sustained adversarial exposure is the S2→S3 readiness measure per IAL §27.S.6.

What the refusal guard does **not** do:

1. **No `interventionRefused` impulse emitted.** The refusal is a JSON response field. Nothing is written to the activity-api store. The `interventionRefused` shape is not registered by any vessel — `openspec/changes/2026-05-23-intervention-tracking/` has all tasks unchecked.

2. **Not a gate on operator interventions.** The guard fires on recommendation requests, not on operator-dispatched interventions. A human operator sending `kubectl delete pod`, modifying `lift-status.json`, or force-pushing to `dev` would not trigger this path.

3. **No rate tracking.** There is no `intervention-rate-tick` aggregator, no `interventionRateReport`, no sustained-window measurement. These are specified in the intervention-tracking spec but unimplemented.

4. **Not adversarial-exposure-tested.** S.6 requires the push-away rate to be measured "under sustained adversarial exposure." The single operator probe is not sustained adversarial exposure.

**What it correctly is:** a recommendation-quality fix that prevents the selector from dispatching confidently-wrong templates when the requested output shapes have no catalogue producer. This is real, useful, and addresses the gap surfaced by the operator probe. It is a legitimate S2-phase improvement. Framing it as §27.S.6 push-away is the overreach.
