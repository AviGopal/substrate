## §5 — Observation channels as vessels (mapping to H1-H4)

Three observation channels, mapped to H1-H4:

### Audit vessel (iter-053 pattern materialized)

- **H2 registration**: audit-vessel generates ed25519 keypair, registers with discovery-vessel advertising `auditAttestation` shape; `vessel_id = multihash(pubkey)`. Self-signed challenge proves keypair possession.
- **H3 attestation shape**: `auditAttestation` impulse body = `{finding_id, execution_id, claim, evidence_cites: [{path, line, literal}], signed_by: vessel_id, signature, observed_at}`. Mirrors substrateGap classification_metadata.
- **H1 two-sided trace**: substrate's own trace_id is cited in the attestation; substrate's verification of attestation produces a co-signed `attestationAccepted` trace record.
- **H4 quorum**: 1 audit attestation alone is advisory; ratification requires `N ≥ 3` from distinct vessel_ids OR 1 from operator-anchored vessel.
- Authority weight: high (operator-ratified via H4 quorum-bypass anchor).

### Cite-checker vessel (already-shipped tool wrapped as vessel)

- **H2**: cite-checker vessel registers, advertises `citeVerificationAttestation`. The script `validation/scripts/cite-check.ts` runs as resolver inside the vessel.
- **H3 attestation shape**: `{finding_id, cite_string, verified: bool, observed_line_text, signature}`. Syntactic-only — the vessel attests "this literal exists at this path:line" not semantic correctness.
- **H1**: attestation references substrate's source-tree commit SHA + the cited file:line.
- **H4**: cite-checker quorum is trivial — one well-signed attestation suffices for syntactic claims because the claim is deterministically verifiable.
- Authority weight: high for syntactic, zero for semantic.

### Dev-agent vessel (implicit bridge made explicit)

- **H2**: each dev session registers ephemerally with `session_id` + signed git-author identity.
- **H3 attestation**: `implementationAttestation` = `{finding_id, commit_sha, files_changed, lines_changed, claim: "closes finding X via Y"}`. Bound to a git commit (verifiable artifact).
- **H1**: substrate co-signs by re-running tests + observing the cited commit lands on `dev` HEAD.
- **H4**: 1 implementation + 1 cite-checker confirming + 1 audit attestation that re-running observation shows finding closed → quorum.
- Authority weight: high (commit artifact is non-repudiable).
