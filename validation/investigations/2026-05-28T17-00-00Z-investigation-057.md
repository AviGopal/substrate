## L4-recursion demonstrated empirically

The meta-question ("which templates fail?") IS structurally unanswerable from inside the substrate. The chain:

1. Operator submits "list failing templates"
2. Substrate routes to escalate-unknown-shape (6th distinct misroute target)
3. escalate-unknown-shape's tasks call resolvers that hit failure paths
4. Proxy catch swallows the failures → all tasks `status:success`
5. Execution reports `status:success`, `failure_mode: null`
6. Output is an unusable error-marker impulse

**The substrate doesn't know which templates fail because the silent-success pattern hides failures from the substrate's own queries.** Asking the substrate to identify its failures uses the same machinery that produces the silent-successes. The question is unanswerable from inside.

This is iter-046's L4 framing made empirical:
- L0 (behavior) — works for the resolvers that complete cleanly
- L1+ (failure observability) — required for the meta-question to be answerable
- L4 (meta-proposal about which observability primitives are missing) — requires L1+L2+L3 to function

Today's substrate is at L0. Asking it L4 questions returns silent-success on whatever template the recommender misroutes to.
