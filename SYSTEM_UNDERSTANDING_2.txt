│ Plan: concept-db Vessel                                                      │
│                                                                              │
│ Overview                                                                     │
│                                                                              │
│ Create a standalone vessel that manages concepts as impulses with graph      │
│ relationships. The vessel exposes MCP tools, runs autonomous upkeep          │
│ activities via Thompson Sampling, and integrates with the existing           │
│ impulse/trace learning system.                                               │
│                                                                              │
│ Key Design Decisions:                                                        │
│ - Concepts ARE impulses (same pointer/budget/priority structure)             │
│ - Resolution creates snapshots (enrichment with actual content)              │
│ - Upkeep rules become autonomous activities (subject to Thompson Sampling,   │
│ create traces)                                                               │
│ - Lifecycle hooks trigger on CRUD operations                                 │
│ - Multi-tenant: global:org:project scoped                                    │
│                                                                              │
│ ---                                                                          │

│ Trigger Condition: token_estimate > budget * 1.5                             │
│ Action: Split into children, create derived_from edges                       │
│ ────────────────────────────────────────                                     │
│ Activity ID: resolve-island                                                  │
│ Trigger Condition: Concept has no edges                                      │
│ Action: Find related concept, create description_of edge                     │
│ ────────────────────────────────────────                                     │
│ Activity ID: adjust-priority-relevance                                       │
│ Trigger Condition: abs(priority - relevance) > 0.3                           │
│ Action: Align priority with relevance (EMA)                                  │
│ ────────────────────────────────────────                                     │
│ Activity ID: prune-irrelevant-neighbors                                      │
│ Trigger Condition: High relevance + low relevance neighbor + low weight edge │
│ Action: Delete weak edge                                                     │
│ ────────────────────────────────────────                                     │
│ Activity ID: create-sequence-edges                                           │
│ Trigger Condition: Execution trace has multiple concept inputs               │
│ Action: Create sequence_next/prev edges                                      │
