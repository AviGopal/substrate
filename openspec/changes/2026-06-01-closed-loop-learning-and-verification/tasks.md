# Tasks — Phase 3 closed-loop learning and verification

Goal: with no operator input beyond initial config, the substrate detects a recurring pattern, drafts an activity, verifies it, and refines via disagreement traces. The transfer test is this phase's acceptance.

- [ ] **3.1** — Implement `detect-recurring-pattern` in `repos/development-vessel/src/seed/detect-recurring-pattern.ts`. Trace-store query + windowed clustering across Layer-1/2/3 outputs. Default threshold `n_occurrences ≥ 5`. Emits `recurringPatternCluster` with contrast examples and `n_concept_citations_available` derived from concept-db lookups. **Acceptance:** seeded with a fixture trace stream containing 6 occurrences of a target episode-signature plus distinct contrast traces, the activity emits one `recurringPatternCluster` with the correct `pattern_id` and `contrast_examples.length ≥ 1`; clusters lacking any contrast trace are suppressed.

- [ ] **3.2** — Implement `predict-and-verify` in `repos/development-vessel/src/seed/predict-and-verify.ts`. Routes verification by the candidate's `declared_output_shapes`: `intentLabel` → behavioural-continuation verifier; `trajectoryPrediction` → sequence-match verifier; `assistanceAction` → state-change verifier. Mixed candidates run all applicable verifiers and require AND-conjunction for promotion. Emits `verifierResult` on success and `prediction_disagreement` with the appropriate sub-case on miss. **Acceptance:** three positive-path fixtures (one per output-shape) each emit `verifierResult` only; three negative-path fixtures each emit `prediction_disagreement` with sub-case (`intent_inconsistency`, `trajectory_divergence`, `action_no_effect`) and populated context; a mixed-output positive fixture requires both verifiers green for promotion.

- [ ] **3.3** — Implement `refine-on-disagreement` in `repos/development-vessel/src/seed/refine-on-disagreement.ts` as a lifecycle subscriber on `prediction_disagreement` traces. Reads the failure sub-case, dispatches `draft-activity-from-pattern` for a variant addressing the specific disagreement, and integrates the variant via `propagateCreditAlongChain` at `repos/metabob-activity-api/src/services/posterior-update.ts:386-392`. **Acceptance:** an `action_no_effect` disagreement on activity A causes the refiner to dispatch the drafter and produce a refined `authoredActivityCandidate` referencing the parent activity; the parent's α/β posterior reflects the chain-credit propagation; refined candidates pass the Phase 2 comprehensibility and registration-invariant gates.

- [ ] **3.4** — Wire posterior-treatment scaling per the umbrella discipline: `action_no_effect` increments variant β by 1.0; `intent_inconsistency` and `trajectory_divergence` increment β by 0.5. Mirrors the `confidence_tier` scaling in `2026-05-31-display-failure-mode-extensions`. Register the Layer-2/3/4 shapes (`intentLabel`, `trajectoryPrediction`, `assistanceAction`) in concept-db. **Acceptance:** unit tests confirm the β-delta on each sub-case; the three shapes are queryable in the concept-db registry; an `assistanceAction` write with `reversibility_class: "unknown"` is rejected per the umbrella shape contract.

- [ ] **3.5** — Phase 3 transfer-test instrumentation + operator-checklist closure. Build a 7-day-window observer that tracks (a) ≥ 1 promoted substrate-authored Layer-2 activity, (b) ≥ 1 promoted Layer-4 activity, (c) aggregate Thompson posterior mean ≥ 0.6 against uniform-random with sample count ≥ 30, (d) ≥ 1 autonomous `refine-on-disagreement` firing. Operator-side decisions from umbrella design §14 (multi-action `interactionTriple` shape ratified, vault-content denylist policy ratified, synthetic n=0 confirmation step installed, operator-feedback channel marked opt-in) MUST be checked off before this phase merges. **Acceptance:** with no operator-curated scenario JSON entering the pipeline during the 7-day window, all four transfer-test criteria hold and the operator may declare Phase 3 closed; the first observable milestone (Layer-2 promotion) may be reported independently before Layer-4 ships.
