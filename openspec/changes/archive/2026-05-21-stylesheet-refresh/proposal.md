# Proposal: Stylesheet refresh

## Why

The cloud-dashboard has accumulated visible UI debt that is
identifiable without subjective judgement:

1. `/mcp` uses a **hand-rolled tabs control** because the shadcn
   `Tabs` primitive wasn't installed (`MCPSurfacePage.tsx` lines
   36–57). The component comment ("Tabs primitive isn't in the
   shadcn registry shipped with this dashboard...") flags this
   as known-deferred work.
2. `Sidebar.tsx` ships an inline `Icon` helper that maps icon
   names to **emoji glyphs** (🔑, 📦, 🔍, etc.) despite
   `lucide-react` being a dependency.
3. `/api-keys` exposes a **200+ character key fingerprint** via
   `<code>{maskKey(apiKey.prefix)}</code>` (28 mask chars + prefix).
   At 375px viewport this wraps awkwardly even with the existing
   `block truncate` class because the parent flex column can't
   constrain it without an explicit `max-w`.
4. The `KeyRow` meta-row uses `flex-wrap items-center` without a
   tightened `gap`, so the badges (`created X · N/M conn ·
   show usage`) wrap with inconsistent vertical rhythm.
5. There is **no design-token surface**. Colours, spacing, radii,
   and shadows are scattered Tailwind utilities; refactors touch
   many files for what should be one variable change.

The sibling `ui-audit` change provides a measurement baseline.
This change ships fixes targeted at observable violations from
that baseline.

## What changes

- Install shadcn `Tabs` primitive (`bunx shadcn add tabs`).
  Replace `MCPSurfacePage`'s inline tabs with `Tabs` / `TabsList`
  / `TabsTrigger` / `TabsContent`.
- Replace `Sidebar.tsx`'s emoji-glyph `Icon` helper with
  `lucide-react` icons. The two currently-rendered nav items use
  `Key` (for `key`) and `Boxes` (for `boxes`); the unused
  glyph map (grid, activity, folder, alert-circle, search,
  trending-up, users, settings) is deleted.
- Refactor `APIKeysPage`'s key-fingerprint surface: wrap the
  `<code>` in a constrained container with `truncate max-w-xs
  font-mono text-xs` and add a copy-to-clipboard button (lucide
  `Clipboard` icon) immediately after. The button uses the
  existing copy pattern from `NewKeyBanner`.
- Tighten the `KeyRow` meta-row to
  `flex items-center gap-2 flex-wrap text-sm tabular-nums`
  with explicit gap; remove the redundant `gap-x-3 gap-y-0.5`.
- Introduce `src/styles/tokens.css` defining
  `--text-scale-*`, `--space-scale-*`, `--radius-*`,
  `--ring-color`, and the existing colour palette as
  `--color-*` custom properties under `@layer base`.
  Import into `src/styles/index.css` ahead of Tailwind layers.
- Wire tokens into `tailwind.config.ts` via the `theme.extend`
  block so component code can continue using utility classes
  (`text-foreground`, `rounded-md`, etc.) and the tokens are the
  underlying definition. This is the minimum-friction migration;
  no component-level changes required for the tokenisation work.
- Verify against `ui-audit`: post-refresh overflow + truncation
  + tap-target counts MUST drop by ≥ 50% vs. a pre-refresh
  baseline captured before this change lands. axe-count MUST
  NOT increase.

## Impact

- `repos/metabob-cloud-dashboard/package.json` — possible new
  shadcn-generated dependency entries (`@radix-ui/react-tabs`).
- `repos/metabob-cloud-dashboard/src/shared/components/ui/tabs.tsx`
  — new (generated by shadcn CLI).
- `repos/metabob-cloud-dashboard/src/features/mcp/MCPSurfacePage.tsx`
  — replace inline tabs.
- `repos/metabob-cloud-dashboard/src/shared/components/Sidebar.tsx`
  — swap icons.
- `repos/metabob-cloud-dashboard/src/features/api-keys/APIKeysPage.tsx`
  — constrain fingerprint, add copy button, tighten meta-row.
- `repos/metabob-cloud-dashboard/src/styles/tokens.css` — new.
- `repos/metabob-cloud-dashboard/src/styles/index.css` — add import.
- `repos/metabob-cloud-dashboard/tailwind.config.ts` — extend with
  token references.

No backend impact. No env-var changes.

## Risks

- **Tabs primitive ARIA divergence.** The hand-rolled tabs use
  `role="tablist" / role="tab" / role="tabpanel"`; the shadcn
  Tabs primitive is Radix-backed and may add focus-management
  side-effects (arrow-key navigation, focus rings). Existing
  rubric specs that click `button` elements may need to target
  by accessible name instead. Mitigation: the rubric spec
  currently doesn't target the tabs by attribute; verify before
  merging.
- **Token migration scope creep.** The temptation is to "fix
  all spacing" while introducing tokens. Resist. The change
  introduces the tokens file and wires Tailwind to it; it does
  NOT rewrite component-level utility classes. That's a future
  pass once the tokens have a real shape.
- **Copy-to-clipboard browser variance.** `navigator.clipboard`
  isn't universally available (Safari requires HTTPS or
  localhost). The button SHALL gracefully no-op when clipboard
  is unavailable, matching the `NewKeyBanner` pattern.
- **lucide-react bundle size.** Already a dependency; the
  Sidebar change does not increase bundle (tree-shaking handles
  unused icons).

## Non-goals

- No dark-mode polish beyond what existing tokens support.
- No theme switcher.
- No full design-system migration (no Radix overhaul,
  no replacement of Tailwind with a CSS-in-JS layer).
- No replacement of `<UsageBadge>` or `<IntentBreakdown>` styling —
  those landed in their own changes.
- No mobile-specific navigation re-think (the existing
  mobile-drawer pattern stays).
- No keyboard-shortcut overhaul.
