# Phase 4 (budget) — smallest design

**Envelope record.** A standing pool impulse, shape `spendEnvelope`, body
`{usd_cap_per_hour?: number, paused?: boolean, reason?: string}`, written with
`poolImpulse_write` (fixed id `spend-envelope`). No new store, no debit writes, no new
registration: `poolImpulse` is already served by every development-vessel with a
node-unique id and a routable endpoint (`development-vessel-local` @ :18090,
`development-vessel-compose2` @ :26090; cross-node reads verified 200).

**Owner = newest record across the fleet.** The helper asks discovery for every
`poolImpulse` producer, reads open `spendEnvelope` records from each, and takes the newest
`updated_at`. A record written on either node binds both; the operator writes it on the hub.
This replaces a `unique_authoritative` registration (which would need a profile-dependent
registration and a new resolver pair) with the same effect: one live record, read at use time.

**Spent.** Sum over every distinct `llmSpendSummary` producer discovery lists (deduped by
resolve url; absolute `resolve_endpoint` used as-is, a path is joined to `endpoint`) of
`current.cost_usd + previous.cost_usd × max(0, 1 − elapsed/window_ms)` (a sliding hour).

**Verdict** (`spendEnvelopeAllows()`, cached 30 s):
- no record, or no numeric cap and not paused → allow (behaviour unchanged; safe to land first)
- `paused:true` → block · spent ≥ cap → block
- any discovered pool producer (or, with a cap, spend producer) not answering → `unreadable`
  → block, once this process's last complete read found a record (before that: no cap, so
  landing and the pinned fail-open capacity test are unchanged). Partial = unreadable because
  a partial read could miss the one node holding the pause. Cost: a peer outage blocks
  composes on the other node until discovery ages the peer out; a process restarted during a
  hub outage fails open until it reads once. Cheap ticks are not gated by this helper.

**Where it lives.** One exported helper in `development-vessel/src/resolvers/gap-to-feature.ts`
beside `llmProducerAdvertised` (it already imports `DISCOVERY_ENDPOINT`/`METABOB_API_KEY`).
- (a) auto-pick: pre-selection block, after lease, capacity and LLM probes → non-attempt
  `{stage:"budget", verdict:"BUSY", skipped_selection:true}` (BUSY ⇒ `isNonAttemptComposeResult`).
  Covers the in-process nudge, gap-compose.service ticks, drain observer and restart picks.
- (c) `bumpFailedAttempts`' "investigate and decompose" `/run-goal` fetch: gated. All its
  callers are post-selection, so a failing DIRECTED compose (gap_id) reached it past (a) —
  the storm shape in the 4.2 evidence. (The low-confidence "investigate gap … before composing"
  route runs only on auto-picks, so (a) covers it.)
- (b) substrate-gap nudge: dynamic-imports the helper; blocked ⇒ neither the unit start nor
  the in-process compose; the 60 s throttle is not stamped. Also avoids the false
  "pickup triggered" log that the null-proc path prints.

**Landing order: 4.1 (gap-to-feature) BEFORE 4.2 (substrate-gap)**; 4.2 alone does not typecheck.

**Known limits (state them, do not hide them).**
- Cross-node spend is NOT summed today: both llm-resolvers register the same id
  `llm-resolver-vessel` with a loopback endpoint, and compose2 does not publish P220, so each
  node's discovery lists only its own. Until prerequisite 4.0 lands (per-node
  `LLM_RESOLVER_VESSEL_ID` — hook exists at llm-resolver index.ts:51 — plus a routable
  advertised endpoint and P220 published), the cap is enforced per node: effective global cap
  ≈ 2 × `usd_cap_per_hour`. The helper becomes global with no code change once both register.
- `llmSpendSummary` is in-memory (a restart resets it); a non-numeric cap reads as no cap.
- `GAP_COMPOSE_CATEGORY` on the tick passes `category`: bypasses lease, capacity, this gate.
- Awaited in the gap-write handler: ≤ 2 rounds × 3 s worst case, 30 s cache; the self read
  (dev-vessel → its own :P090) fails closed if its HTTP is starved.

**Remaining.** 4.3 boredom/rhythm (separate vessels): a copy of the pool-read half only —
pause check through discovery (not 127.0.0.1:8090), newest record wins, fail OPEN for cheap
ticks; `paused:true` replaces budget>1. 4.4 breaker is goal-host (`handleRunGoal`, `/resolve`),
independent of this helper. 6.1 writes the first record.
