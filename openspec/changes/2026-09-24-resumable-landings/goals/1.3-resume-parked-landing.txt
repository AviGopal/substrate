Changes, all in this one file:
(1) Add `resume_from?: ParkedLanding` and `parked_landing_ttl_ms?: number` to FeatureComposePointer.
(2) Add a module-level `async function resumeParkedLanding(pointer: FeatureComposePointer, park: ParkedLanding, toolsEndpoint: string): Promise<ResolverResult | null>` that:
  a. STALENESS: for each park.files entry whose base_content is not null, read the push-clone file `/workspace/git/vessels/${park.vessel}/${f.path}` (callTool(toolsEndpoint, "fs_read", { path })); if its content !== f.base_content the base moved: `await deleteParkedLanding(park.gap_id)`, `await appendComposeLesson("park_stale", \`parked diff for ${f.path} no longer applies: base moved since ${park.parked_at}\`, park.vessel, pointer.gap)`, log `[feature-compose] park_stale for ${park.gap_id} — base moved, redrafting`, and return null (the caller falls through to a normal draft).
  b. Log exactly `[feature-compose] RESUMING parked landing for ${park.gap_id} (parked ${Math.round(ageMs/60000)}m ago)`.
  c. Snapshot each live file `${RUNTIME_ROOT}/${park.vessel}/${f.path}` (same RUNTIME_ROOT the landing loop uses), then write f.content to the live path and into a staging dir `${REPO_ROOT}/${park.vessel}-mitosis-resume-${ts}/${f.path}` (same REPO_ROOT/mitosis naming as the landing loop).
  d. TYPECHECK ONLY (no drafter call, no bun test): callTool(toolsEndpoint, "shell", { command: `cd ${RUNTIME_ROOT}/${park.vessel} && timeout 300 bunx tsc --noEmit -p . 2>&1 | tail -20; echo TC_EXIT=\${PIPESTATUS[0]}` }). If TC_EXIT is not 0: restore the snapshots, delete the park, append a `park_stale` lesson with the tsc tail, return null.
  e. Call resolveVesselMitosisCutover with the same fields the landing loop passes (vessel_name, base_version_id `${vessel}-live`, mitosis_version_id `${vessel}-resume-${ts}`, mitosis_root = the staging dir, staged_files = park paths, staged_base_sha = first 12 hex of sha256 of the first file's content, gap_id, proposal_id `${gap_id}-compose-report`, evaluation_evidence FAVORABLE citing ["typecheck (resume)", "parked: shape-dispatch", "parked: bun test (baseline-delta, flake-confirmed)"]).
  f. If the result has push_status "pushed" and a new_git_sha: delete the park and return `{ shape: "featureComposeReport", body: { ok: true, verdict: "FAVORABLE", resumed_from: park.compose_id, parked: false, cutovers: [{ vessel, result }] } }`. Otherwise restore the live snapshots (an uncommitted live edit poisons the next baseline), keep the park, log `[feature-compose] cutover did not land — verified patch parked for ${gap_id}`, and return the same shape with ok:false, verdict "UNFAVORABLE", parked: true. Always rm -rf the staging dir.
