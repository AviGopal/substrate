(1) Rename the CURRENT body of validateMaintenanceLease, unchanged, into a non-exported `function validateLeaseFile(leasePath: string, token: string | undefined | null, now: Date): LeaseValidationResult` (same checks, same error strings, never throws).
(2) Re-implement `export function validateMaintenanceLease(leasePath, token, now = new Date())` as: `const primary = validateLeaseFile(leasePath, token, now); if (primary.ok || !token || typeof token !== 'string') return primary;` then `let names: string[] = []; try { names = readdirSync(dirname(leasePath)); } catch { return primary; }` and `for (const f of names) { if (!/^maintenance-.+\.json$/.test(f)) continue; const r = validateLeaseFile(join(dirname(leasePath), f), token, now); if (r.ok) return r; }` and finally `return primary;` — so EVERY primary failure (missing, unparsable, expired, token mismatch) falls through to the named files, and when none matches the caller still gets the primary's original error.
Import readdirSync (node:fs) and dirname (node:path) alongside the existing imports.
