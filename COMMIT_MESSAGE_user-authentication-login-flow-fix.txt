feat(auth): Fix user authentication and login flow

## Instructional State Change

**Requirement**: Users created via CLI must be able to authenticate and login to the dashboard. Login endpoint must return JWT tokens for valid credentials.

**Before**: Users could not login - CLI-created users failed authentication with 401 Unauthorized errors. Root causes:
1. Users table schema missing from database
2. SurrealDB query result parsing incorrect (accessing outer dict instead of user record)
3. User ID format with hyphens causing parse errors during creation

**After**: Complete authentication flow working end-to-end:
- Users created via CLI persist to database with proper schema
- Login endpoint correctly extracts user data from nested SurrealDB results
- Password verification succeeds with bcrypt
- JWT tokens generated and returned to dashboard
- Dashboard authentication works

### Login Endpoint Query Parsing (repos/metabob-rpc-api/server/routes/cloud_auth.py:69-107)
**Before**:
```python
user_data = result[0]  # BUG: Gets outer dict, not user record
```

**After**:
```python
# Handle nested SurrealDB result structure from official surrealdb-py library
user_data = None
first_elem = result[0]

# Case 1: Official library format {"status": "OK", "result": [...]}
if isinstance(first_elem, dict) and "result" in first_elem:
    user_list = first_elem.get("result", [])
    user_data = user_list[0] if user_list else None
    logger.debug(f"Parsed user from result dict: {user_data.get('user_id') if user_data else None}")

# Case 2: List of records [[{...}]]
elif isinstance(first_elem, list) and len(first_elem) > 0:
    user_data = first_elem[0]
    logger.debug(f"Parsed user from result list: {user_data.get('user_id') if user_data else None}")

# Case 3: Direct record (legacy or simplified format)
elif isinstance(first_elem, dict) and "email" in first_elem:
    user_data = first_elem
    logger.debug(f"Using direct result dict: {user_data.get('user_id')}")

if not user_data:
    logger.warning(f"Login failed: could not extract user data from result for email {request.email}")
    raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Invalid email or password")
```

### User ID Format (repos/metabob-rpc-api/server/db/operations/user_ops.py:52)
**Before**:
```python
user_id = f"user-{uuid.uuid4().hex[:12]}"  # Hyphens cause SurrealDB parse error
```

**After**:
```python
user_id = f"user_{uuid.uuid4().hex[:12]}"  # Underscores work natively in SurrealDB
```
