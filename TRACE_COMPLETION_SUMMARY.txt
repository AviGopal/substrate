
## Trace Complete: dashboard-activity-history-viewing-flow

### Summary
Traced the complete end-to-end flow for viewing activity history in the Metabob dashboard. Identified all components from Kubernetes infrastructure through frontend UI to backend API and database.

### Key Findings

**Working Components:**
- Kubernetes cluster (docker-desktop context) with services deployed
- Dashboard UI with DevelopmentProgressDashboard and LearningView components
- Activity execution write path (POST /v2/activities/executions → SurrealDB)
- SurrealDB storage with activity_executions table
- Playwright browser automation tools

**Critical Gaps (3):**
1. **Analytics Router Missing** - repos/metabob-rpc-api/server/routes/analytics.py does not exist
2. **Aggregation Logic Missing** - No functions to compute template statistics from executions
3. **Router Registration Missing** - analytics_router not included in FastAPI app

**Data Flow:**
- WRITE PATH ✓: OpenCode → POST /v2/activities/executions → SurrealDB
- READ PATH ✗: Dashboard → GET /analytics/* → 404 NOT FOUND
