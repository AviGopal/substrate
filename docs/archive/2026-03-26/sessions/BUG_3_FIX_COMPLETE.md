## Problem Summary

The `create-activity-self-contained` template's Task 3 (write-template-json) was failing with "Missing variables" errors because:

1. **Documentation examples** in code blocks used placeholder syntax like `{{variableName}}` and `{{foo}}`
2. **Structural examples** in code blocks used real variables like `{{templateName}}` that needed to be replaced
3. The original `interpolatePrompt()` couldn't distinguish between these two use cases

### Failure Scenario

```
Task 3 prompt contains:
```json
{
  "name": "{{templateName}}",        // ← Should be replaced with actual value
  "prompt": {
    "template": "Use {{variableName}} for interpolation"  // ← Documentation example
  }
}
```

Rule: If prompt has `{{foo}}`, include it  // ← Inline code example
```

**Expected behavior:**
- Replace `{{templateName}}` → "My Template Name"
- Preserve `{{variableName}}` (documentation example)
- Preserve `{{foo}}` (inline code example)

**Previous behavior:**
- Attempted to replace all `{{}}` placeholders
- Threw error: "Missing variables: {{variableName}}, {{foo}}"

---

## Solution

Modified `interpolatePrompt()` in `activity-template.ts` to be **context-aware**:

### New Logic

1. **Still replace all provided variables** (including in code blocks)
2. **When checking for missing variables**, filter out placeholders that appear in:
   - Fenced code blocks (```)
   - Inline code (`)
3. **Only throw errors** for missing variables in regular text

### Code Changes

```typescript
// Check for missing variables, but be lenient with those in code contexts
const remainingVars = result.match(/\{\{([^}]+)\}\}/g)
if (remainingVars) {
  // Filter out variables that appear only in code contexts
  const missingVars = remainingVars.filter(varName => {
    const inFencedBlock = /```[\s\S]*?```/g.test(result) && 
      new RegExp(`\`\`\`[\\s\\S]*?${varName.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')}[\\s\\S]*?\`\`\``).test(result)
    
    const inInlineCode = new RegExp(`\`[^\`]*${varName.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')}[^\`]*\``).test(result)
    
    return !inFencedBlock && !inInlineCode
  })

  if (missingVars.length > 0) {
    throw new Error(`Missing variables: ${missingVars.join(", ")}`)
  }
}
```

## Template Authoring Guidelines (New)

### Using Placeholders in Prompts

**For real variables:**
```
Create {{fileName}}.ts with {{featureName}} implementation
```

**For examples in code:**
```typescript
// Inline code: `{{variableName}}`
// Fenced blocks:
```json
{
  "template": "Use {{variableName}} for interpolation"
}
```
```

**These will be tolerated** (no error thrown) even if not declared.

**For safety:** Variables in regular text MUST be declared or error will be thrown.
