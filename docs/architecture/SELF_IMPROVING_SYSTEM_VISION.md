# The Self-Improving System: Conscious → Subconscious Execution

## Vision

A system that learns optimal workflows, compiles them into efficient implementations, and progressively removes LLM mediation.

**Core Insight**: "This is basically all software is. But also it is the process of moving things from the conscious → subconscious."

## The Three Layers

### 1. Learning (Conscious)
- Full LLM mediation
- Expensive ($1.42/task)
- Flexible (handles novel cases)
- Learning what tools, order, parameters

### 2. Pattern Recognition (Habit)
- After 10+ executions
- 80% follow same sequence
- Identify compilation candidates

### 3. Compilation (Subconscious)
- Direct tool calls
- 99.9% cheaper ($0.001/task)
- 10x faster (200ms vs 2000ms)
- LLM fallback for edge cases

## Key Components

### Cognitive Load Reduction
- Current: 50+ tools in prompt
- Optimized: 5 tools per task type
- 80% token reduction
- 3x faster reasoning

### Self-Composition
- System observes user workflows
- Suggests compositions automatically
- Optimizes over time (parallelize, skip steps)

### Model Optimization
- Novel → Claude Sonnet ($1.0)
- Familiar → GPT-4o ($0.3)
- Routine → GPT-4o-mini ($0.1)
- Compiled → No LLM ($0.001)

### Abstraction Climbing
- Year 1: Basic ops (edit file)
- Year 2: Features (add auth)
- Year 5: Systems (microservice)
- Year 10: Novel paradigms

## Metrics

**Cost Reduction**:

**Speed Improvement**:
