### ✨ Key Features

- ✅ **Smart Analysis**: Identifies entry/exit, branches, errors, loops, external calls
- ✅ **Context-Aware Log Levels**: DEBUG for internal flow, INFO for operations, ERROR for failures
- ✅ **Validated**: Ensures functionality intact with typecheck and tests
- ✅ **Selective**: Target specific functions or entire files
- ✅ **Convention Following**: Matches OpenCode's `Log.create()` pattern
- ✅ **Anti-Pattern Detection**: Catches console.log, string concatenation, etc.
- ✅ **Project-Agnostic**: Auto-detects test and typecheck commands
- ✅ **Production-Ready**: Supports minimum log level filtering

### 📊 Variables

| Variable | Required | Type | Default | Description |
|----------|----------|------|---------|-------------|
| `targetFile` | ✅ | string | - | Path to file to add logging to |
| `functionName` | ❌ | string | - | Specific function (optional, default: all functions) |
| `logLevel` | ❌ | string | `"INFO"` | Minimum level: DEBUG, INFO, WARN, ERROR |

---

### 🎨 What Gets Logged

- **Function Entry/Exit**: Parameters, return values, success/failure
- **Decision Branches**: Which branch taken and why
- **Error Paths**: Caught exceptions with context
- **Loops**: Entry, progress, completion
- **External Interactions**: API calls, file I/O, database queries
- **Performance Timing**: Using `log.time()` pattern

---

### 🔍 Anti-Pattern Detection

Automatically catches:
- 🚨 `console.log()` instead of `log.info()`
- 🚨 String concatenation
- 🚨 Missing logger setup
- 🚨 Wrong log levels
- 🚨 Logging sensitive data
- 🚨 Empty extra data objects

  log.debug("user_fetched", { userId, status: user.status })
  
  if (user.status === "active") {
