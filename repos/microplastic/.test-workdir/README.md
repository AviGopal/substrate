# Microplastic - Composite Vessel Agent-IDE

A lightweight, modular agent-IDE designed for vessel development and composition.

## Features

- **Vessel Management**: Create, edit, and manage vessel agents
- **Composite Architecture**: Support for multi-agent collaboration
- **Interactive Development**: Real-time development environment
- **Tool Integration**: Built-in support for common development tools

## Project Structure

```
microplastic/
├── src/
│   ├── core/           # Core vessel engine
│   ├── ide/           # IDE interface components
│   ├── agents/        # Agent definitions and templates
│   └── tools/         # Development tools integration
├── config/            # Configuration files
├── examples/          # Example vessels and compositions
└── tests/            # Test suite
```

## Getting Started

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Open the IDE at `http://localhost:3000`

## Development

This project follows a modular architecture where vessels can be composed and orchestrated through the IDE interface.
